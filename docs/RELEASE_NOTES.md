# KinTime 0.2.1

Removes the manual activity timer and logging screen. The app focuses on family screen-time tracking, app usage, and optional Reels/Shorts estimates.

- Restores Today, Family, and Tracking navigation.
- Removes timer controls, project fields, manual entries, and their documentation/screenshots.
- Preserves existing screen-time and short-video history when upgrading from 0.1.0 or 0.2.0. The obsolete manual-entry table is removed during the 0.2.0 upgrade.

## Install

Download **KinTime-android.apk** on an Android 15+ phone. This is a development build signed with the same local Android debug certificate as the previous release. **SHA256SUMS** is included for download verification.

Enable screen-time tracking in Tracking → Usage Access. Optional short-video estimates require separate consent and Accessibility setup. Family sharing still requires your Firebase project; see the setup guide in the README.
